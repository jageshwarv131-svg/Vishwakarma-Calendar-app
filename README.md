# Vishwakarma Panchang – Android App

This Android project wraps the **VISHWAKARMA JI – पंचांग कैलेंडर** HTML application directly inside a mobile-friendly, all-device-compatible Android WebView app (`app/src/main/assets/index.html`) without altering any features, logic, or UI.

## How to Build & Download the APK on GitHub

1. Push this project to a GitHub repository (`main` or `master` branch).
2. GitHub Actions (`.github/workflows/build-apk.yml`) will automatically start building `Vishwakarma-Panchang.apk`.
3. Once the workflow finishes:
   - Go to **Actions → Build Vishwakarma Panchang APK** and download **Vishwakarma-Panchang-APK** from **Artifacts**, **or**
   - Go to **Releases → Vishwakarma Panchang APK** on your repository page and download `Vishwakarma-Panchang.apk` directly onto your Android phone.
